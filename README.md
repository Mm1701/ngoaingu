# Language Learning (static, Supabase)
1. Tạo project Supabase → SQL Editor → chạy `supabase.sql`.
2. Authentication → bật Email (tắt "Confirm email" nếu muốn đăng nhập ngay).
3. Settings → API: lấy URL + anon key → điền `js/config.js` (không dùng service_role).
4. Chạy: `python3 -m http.server` rồi mở http://localhost:8000 (hoặc deploy GitHub Pages / Netlify / Vercel).
5. Đăng ký → mục **Dữ liệu** → upload Excel (cột: No, Level, Tieng Trung, Pinyin, Tieng Viet, giai thich) hoặc Load Demo → **Học**.
